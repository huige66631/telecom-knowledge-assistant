# Demo Script

这份脚本适合在面试、项目展示或录屏时使用。

## 演示前准备

1. 启动 FastAPI
2. 启动 Streamlit
3. 上传以下样例文档：
   - `samples/telecom_docs/device_management_guide.md`
   - `samples/telecom_docs/interface_stability_test_spec.md`

## 推荐演示顺序

### 1. 先讲项目定位

可以这样说：

> 这个项目不是通用聊天机器人，而是一个面向通信/电子行业资料场景的企业知识助手 Agent。它的重点是上传企业资料、做知识检索、给出引用回答，并支持 KB-first 路由和 SQLite 持久化的会话记忆。

### 2. 展示文档上传

操作：

- 上传 `device_management_guide.md`
- 上传 `interface_stability_test_spec.md`

说明点：

- 支持资料入库
- 会做轻量清洗、切分和本地向量索引
- 支持本地知识库构建

### 3. 演示基础问答

问题：

`某型号交换机支持哪些管理协议？`

说明点：

- 系统会先检索知识库
- 再根据检索结果生成回答
- 页面会展示引用片段

### 4. 演示细节追问

问题：

`SNMP 有哪些限制？`

说明点：

- 展示知识库问答的准确性
- 展示引用来源和命中信息

### 5. 演示多轮记忆

问题：

`继续问：那热插拔恢复时间要求是多少？`

说明点：

- 展示会话级上下文能力
- 说明会话会写入 SQLite，本地刷新和服务重启后仍可恢复

### 6. 演示刷新恢复

操作：

- 提问 1 到 2 轮之后刷新页面

说明点：

- 地址栏里的 `session_id` 会保留
- 页面会重新拉取历史会话和记忆摘要
- 这不是单纯的前端临时状态

### 7. 演示越界问题

问题：

`今天天气怎么样？`

说明点：

- 系统会识别问题超出知识库范围
- 体现 KB-first Agent 的路由逻辑

## 面试时可强调的技术点

- `FastAPI + Streamlit` 的轻量工程落地
- `关键词检索 + 本地向量检索 + RRF` 的混合检索设计
- `LangGraph` 实现 KB-first Agent 路由
- 引用回答与 SQLite 持久化会话记忆
- 可本地运行，也支持 Docker 部署
