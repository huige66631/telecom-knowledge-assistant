# SRT-8600 交换机管理协议说明

## 1. 产品概述

SRT-8600 是一款面向园区网络与企业汇聚场景的二层/三层交换设备，支持远程管理、接口诊断和基础安全控制。

## 2. 管理协议支持

- 设备支持 `SNMPv2c` 与 `SNMPv3`，用于状态监控、Trap 上报和性能采集。
- 设备支持 `SSH` 远程命令行管理，默认启用本地账号认证。
- 设备支持 `HTTPS` Web 管理界面。
- 设备兼容 `Telnet`，但仅建议在隔离测试环境中临时开启。

## 3. SNMP 使用限制

- 当启用 `SNMPv3` 时，必须配置认证与加密参数。
- 在生产网络中，不建议保留默认 community 字符串。
- Trap 上送地址最多可配置 4 组。

## 4. 维护建议

- 建议优先使用 SSH 与 HTTPS。
- 若启用 Telnet，应在测试结束后关闭。
