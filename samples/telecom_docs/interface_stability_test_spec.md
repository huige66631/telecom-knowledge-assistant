# 接口稳定性测试规范（节选）

## 1. 适用范围

本规范适用于企业接入交换机、工业以太网交换机以及通信配套板卡的接口稳定性验证。

## 2. 关键测试项

### 2.1 端口长稳测试

- 24 小时持续转发测试期间，端口不得出现异常 down/up 抖动。
- 在 70% 线速负载下，丢包率应小于 `0.01%`。
- CPU 利用率峰值不应长期高于 `85%`。

### 2.2 热插拔恢复

- 光模块热插拔后，接口应在 `30 秒` 内恢复为可转发状态。
- 恢复后需重新校验速率、双工和错误计数器状态。

### 2.3 管理面连通性

- 在业务转发压力测试过程中，SSH 管理会话不应异常断开。
- SNMP 轮询超时率不应超过 `1%`。
